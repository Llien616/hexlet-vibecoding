# Метрика — калькулятор ИМТ и дневной нормы калорий

Учебный эксперимент в рамках [hexlet-vibecoding](https://github.com/Llien616/hexlet-vibecoding).
Одна статичная страница без сборки и зависимостей: считает индекс массы тела, дневную норму
калорий и БЖУ, пока вы вводите данные.

## Что умеет

- ИМТ по классификации ВОЗ с измерительной шкалой и здоровым диапазоном веса;
- дневная норма калорий по формуле Миффлина — Сан Жеора с учётом пола, возраста и активности;
- цель: поддержание веса, дефицит 15% или профицит 10%;
- распределение БЖУ 30 / 30 / 40;
- подсветка ошибок ввода и предупреждение о слишком низкой норме;
- адаптивная вёрстка, клавиатурная навигация, поддержка `prefers-reduced-motion`.

Все расчёты выполняются в браузере. Данные никуда не отправляются и не сохраняются.

## Формулы

- ИМТ = вес (кг) / рост² (м).
- BMR = 10 × вес + 6,25 × рост − 5 × возраст + 5 (мужчины) / − 161 (женщины).
- Дневная норма = BMR × коэффициент активности × коэффициент цели.
- Коэффициенты активности: 1,2 · 1,375 · 1,55 · 1,725 · 1,9.
- БЖУ: 30% белков, 30% жиров, 40% углеводов.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер:

```bash
npx serve .
```

## Структура

```
index.html   разметка страницы
styles.css   оформление и адаптив
app.js       расчёты и обновление результатов
```

Калькулятор — ориентир, а не медицинская рекомендация.
